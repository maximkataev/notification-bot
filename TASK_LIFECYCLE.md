# Task Lifecycle & AI Analysis

## Философия

Задачи сохраняются **AS IS** в базе данных. AI анализирует их только при запуске (утром и вечером), а не при каждом сохранении.

## Состояния задачи

```
┌─────────────┐
│   PLANNED   │  ← новая задача
└──────┬──────┘
       │
       ├─→ (отложить на дату X)
       │   ↓
       └─→ DEFERRED (скрыта до даты X)
           ↓
       (дата X наступает)
           ↓
       Снова видна при анализе
       │
       ├─→ /done
       │   ↓
       │   DONE (выполнена)
       │
       └─→ /cancel
           ↓
           CANCELLED (отменена)
```

## Статусы задачи

| Статус | Что означает | Видна AI | Видна пользователю |
|---|---|---|---|
| `planned` | Активная, может быть выполнена | ✓ Если today или no date | ✓ Всегда |
| `done` | Выполнена | ✗ | ✓ В истории |
| `cancelled` | Отменена | ✗ | ✓ В истории |

## Когда AI анализирует задачи

AI анализирует задачи **только в 2 моменты в день**:

### ☀️ Утро (08:00)
- **Что** → Анализ всех активных задач
- **Результат** → Morning digest в Telegram
- **Отправляет** → Список дел на сегодня с рекомендациями

### 🌙 Вечер (19:00)
- **Что** → Анализ оставшихся активных задач
- **Результат** → Evening digest в Telegram
- **Отправляет** → Что осталось на сегодня, напоминание

## Какие задачи видит AI

```python
async def get_tasks_for_ai_analysis(user_id):
    """
    Возвращает только задачи для анализа:
    - status = 'planned' (активные)
    - when_date IS NULL (нет конкретной даты) ИЛИ
    - when_date <= TODAY (сегодня или раньше)
    """
```

### Пример 1: Задача БЕЗ даты
```
/plan купить продукты

when_date = NULL
↓
AI видит ВСЕГДА (при каждом анализе)
↓
Может быть выполнена в любой момент
```

### Пример 2: Задача НА КОНКРЕТНУЮ ДАТУ
```
/plan в субботу сходить в парк
when_date = "2026-05-10" (суббота)

Сегодня: 2026-05-08 (четверг)
↓
AI НЕ видит (дата в будущем)
↓
Задача скрывается до субботы
↓
В субботу (when_date <= TODAY):
↓
AI видит при анализе в 08:00
```

### Пример 3: Отложенная задача
```
/plan купить подарок
when_date = "2026-06-01" (через месяц)

Сейчас: 2026-05-08
↓
ДЕFERRED (скрыта)
↓
30 дней спустя...
↓
Ближе к 2026-06-01:
when_date <= TODAY
↓
AI начинает видеть (за день-два до)
```

## Сценарии использования

### Сценарий 1: Задача без даты (гибкая)
```
User: /plan позвонить другу
      ↓
      when_date = NULL
      ↓
      08:00 (morning digest):
      AI анализирует → "Позвонить другу"
      Предлагает: "Любое время (гибкая)"
      ↓
      19:00 (evening digest):
      AI вновь анализирует → "Еще в плане"
      Напоминает: "Не забыть позвонить"
```

### Сценарий 2: Задача на конкретный день
```
User: /plan в пятницу встреча с боссом
      ↓
      when_date = "2026-05-10" (пятница)
      Сегодня = 2026-05-08 (четверг)
      ↓
      08:00 четверга:
      AI НЕ видит (дата > today)
      Пользователь НЕ видит в digest
      ↓
      08:00 пятницы:
      when_date = "2026-05-10" <= "2026-05-10"
      AI ВИДИТ → "Встреча с боссом"
      Пользователь получает напоминание
      ↓
      После /done:
      status = "done"
      Больше не видна
```

### Сценарий 3: Отложенная задача
```
User: /plan я подумаю об этом
      when_date = "2026-06-01" (через месяц)
      ↓
      Дни идут...
      ↓
      2026-05-31 (за день до):
      when_date <= "2026-05-31"
      AI начинает видеть
      ↓
      Пользователь получает "Помню о вашей задаче"
```

## Сохранение истории

Задачи **никогда не удаляются** из БД:
- `status = 'done'` — остаются в БД (можно посмотреть историю)
- `status = 'cancelled'` — остаются в БД
- AI не трогает завершенные/отменённые

## Примеры команд

```bash
# Добавить гибкую задачу (без даты)
/plan позвонить маме

# Добавить задачу на конкретный день
/plan в субботу сходить в кино

# Добавить срочную задачу
/plan СРОЧНО купить билеты (выполнить сегодня)

# Отложить задачу на месяц
/plan вернуться к проекту (дата: 2026-06-01)

# Отметить выполненной
/done 1

# Отменить
/cancel 2

# Посмотреть все (включая старые)
/tasks
```

## Выгода этого подхода

✅ **Нет переанализа** — одна задача анализируется max 2 раза в день  
✅ **Экономия токенов** — не вызываем AI при сохранении  
✅ **Полный контроль** — пользователь полностью управляет датами  
✅ **История** — все задачи остаются в БД  
✅ **Предсказуемо** — AI запускается в одно и то же время  
✅ **Гибкий** — можно отложить на любой срок  
✅ **Умные напоминания** — digest только с актуальными делами

    ┌──────────────────────────┐

    │ в Telegram               │
