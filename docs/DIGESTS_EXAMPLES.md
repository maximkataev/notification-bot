# Morning & Evening Digest Examples

AI генерирует contexted digest'ы с объяснением погоды, предпочтений пользователя, и рекомендациями.

## Morning Digest (08:00)

### Пример 1: Дождливый день, активные дела

```
☀️ Доброе утро!

В Тбилиси сегодня идет дождь (температура 16°C), ветер 12 км/ч. 
Идеально для дел в помещении. Вы обычно просыпаетесь в 11:00, 
поэтому предлагаю начать с офисных дел.

📋 Ваше расписание:
• 11:30-12:30 — Ответить на письма (офис, идеально для дождя)
• 14:00 — Встреча в кино (закрытое помещение, застраховано от дождя)  
• 18:00 — Позвонить маме (можно дома)

💡 Совет: спешить не нужно, у вас достаточно времени. 
Возьми зонт на встречу!
```

### Пример 2: Жаркий день, минимум дел

```
☀️ Доброе утро!

В Тбилиси сегодня очень жарко (31°C). Рекомендую заняться 
важными делами утром, а во второй половине дня отдохнуть.
Вы просыпаетесь в 11:00, но сегодня можешь встать пораньше.

📋 Ваше расписание:
• 10:00-11:00 — Купить продукты (пока еще прохладно)
• 19:00 — Прогулка в парке (вечер, когда остынет)

💡 Совет: пей больше воды! Дневные активности минимизированы 
из-за жары.
```

### Пример 3: Нет дел на день

```
☀️ Доброе утро!

На сегодня запланированных дел нет. В Тбилиси хорошая погода (22°C).
Это отличный день для отдыха или личных проектов!

✨ Можешь спокойно заняться своим.
```

### Пример 4: Только гибкие дела (без конкретного времени)

```
☀️ Доброе утро!

В Тбилиси переменная облачность, +19°C. У вас есть 3 гибких задачи
без привязки ко времени. Планируй их в удобный момент.

📋 Гибкие дела (выбери время):
• Позвонить другу (в любой момент, не срочно)
• Обновить резюме (спокойное умственное занятие, идеально в дневное время)
• Подумать о проекте (медитативная задача)

💡 Совет: начни с самого простого, оставь сложное на дневное время
когда ты в тонусе.
```

## Evening Digest (19:00)

### Пример 1: День был продуктивный

```
🌙 Вечерний обзор

Отлично! Ты выполнил 2 из 3 задач сегодня. Это хороший результат.
Остается только одно дело.

📋 Осталось на вечер:
• Позвонить маме (гибкое время, можно сейчас или завтра)

💡 Совет: если есть энергия, позвони маме сейчас — она обрадуется! 
Если устал, перенеси на завтра. Ты заслужил отдых!
```

### Пример 2: Слишком много на вечер, разумнее отложить

```
🌙 Вечерний обзор

День прошел активно, но у тебя еще есть 2 дела. 
Сейчас 19:00, до сна 4 часа.

📋 Осталось:
• Купить подарок (нужно больше часа, может быть сложно вечером)
• Подготовиться к презентации (требует концентрации)

💡 Совет: ты уже много сделал. Рекомендую отложить эти дела на завтра
утром, когда ты в полной боевой готовности. Сегодня отдыхай!
```

### Пример 3: Все выполнено

```
🌙 Вечерний обзор

🎉 Потрясающе! Ты выполнил ВСЕ задачи на день!

Это был продуктивный день. Ты заслужил отдых.
Спокойной ночи! Завтра новые вызовы ждут.
```

### Пример 4: Срочное дело еще в плане

```
🌙 Вечерний обзор

У тебя осталось 1 срочное дело, которое хотелось бы закончить сегодня.

📋 Срочно:
• 🔴 СРОЧНО подготовить отчет (очень важно, дедлайн сегодня)

⏰ Вопрос: у тебя есть 2-3 часа? Если да, советую начать прямо сейчас,
пока ты еще в форме. Это занимает время, но результат будет качественным.
```

## Как AI принимает решения

```
1. Получает список дел
2. Смотрит текущую погоду в Тбилиси
3. Учитывает профиль пользователя:
   - Когда ты просыпаешься
   - Когда спишь
   - Твои предпочтения
4. Анализирует тип каждого дела:
   - Уличное vs в помещении
   - Срочное vs гибкое
   - Требует ли концентрации
5. Генерирует естественный, контекстный digest
   с объяснением ПОЧЕМУ и КОГДА
```

## Что объясняет AI

✅ **Погода** — как влияет на выполнение дел  
✅ **Время суток** — когда ты в тонусе  
✅ **Тип дела** — уличное ли, требует ли сосредоточения  
✅ **Сроки** — какие дела срочные  
✅ **Рекомендации** — практические советы для дня  
✅ **Мотивация** — поддержка и encouragement  

## Примеры погодного контекста

```
Дождь → "Идеально для офисных дел, возьми зонт если выходишь"
Жара → "Лучше заняться делами утром, отдохнуть днем"
Холод → "Минимизируй уличные дела, займись домашним"
Ветер → "Осторожнее с прогулками, лучше в помещении"
Хорошая погода → "Отличный день для активностей на улице"
```

## Архитектура генерирования

```
APScheduler (08:00/19:00)
    ↓
Получить дела для AI анализа
    ↓
Получить профиль пользователя
    ↓
Получить текущую погоду
    ↓
Передать всё в GPT-4o с контекстным промптом
    ↓
GPT-4o генерирует digest на русском с объяснениями
    ↓
Отправить в Telegram с Markdown форматированием
```

Каждый digest — это уникально сгенерированное сообщение
с полным контекстом дня пользователя!
