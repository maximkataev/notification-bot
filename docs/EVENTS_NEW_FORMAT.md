# Новый формат событий для /events команды

## Формат вывода

```
Название события • Дата, Время, Место

Описание на 280 символов

Цена билета: цена. Ссылка: ссылка
```

## Примеры

### Пример 1: Концерт с полной информацией

```
*1. Концерт Guri and Giga Jalagonia • 2026-05-23, 20:00, Gardenia Hall*

Грузинские музыканты представляют традиционную музыку в современном исполнении. Вечер будет наполнен энергией и аутентичными звуками Грузии. Концерт подойдет как опытным меломанам, так и новичкам, желающим познакомиться с культурой страны.

Цена билета: 50-100 GEL. [Ссылка](https://redevents.ge/ru)
```

### Пример 2: Выставка искусства

```
*2. TAF - Tbilisi Art Fair 2026 • 2026-05-24, 10:00, Expo Georgia*

Ежегодная выставка современного искусства с участием художников со всего мира. На ярмарке представлены работы в различных стилях: живопись, скульптура, инсталляции и видео-арт.

Цена билета: 15 GEL. [Ссылка](https://georgia.travel/events)
```

### Пример 3: Нетворкинг-событие

```
*3. Partnership & Networking Party • 2026-05-23, 18:00, Unicorn Embassy*

Встреча предпринимателей, инвесторов и технологических специалистов. Стартапы, питчинги, сетевые мероприятия. Отличная возможность найти партнеров и инвесторов.

Цена билета: 20 USD. [Ссылка](https://www.eventbrite.com/e/partnership)
```

## Структура данных события

Каждое событие содержит:

```python
{
    "title": str,              # Название события
    "date": str,               # Дата (YYYY-MM-DD)
    "time": str,               # Время (HH:MM)
    "location": str,           # Локация/место проведения
    "description": str,        # Полное описание (280+ символов)
    "price": str,              # Цена билета
    "url": str,                # Ссылка на событие
    "category": str,           # Категория (concert, exhibition, etc.)
    "source": str,             # Источник (redevents.ge, eventbrite.com, etc.)
}
```

## Генерация описаний

**Описания автоматически генерируются через ChatGPT (gpt-4o)**:

- **Длина**: максимум 280 символов
- **Язык**: русский
- **Содержание**: информативное и привлекательное описание события
- **Таймаут**: пропускается, если GPT недоступен (используется пустое описание)

### Примеры сгенерированных описаний

```
"Грузинские музыканты представляют традиционную музыку в современном исполнении. 
Вечер будет наполнен энергией и аутентичными звуками Грузии."
```

```
"Встреча предпринимателей и инвесторов. Презентации стартапов, нетворкинг, 
возможность найти партнеров и финансирование для вашего проекта."
```

## Команда использования

```
/events
```

**Результат**: список всех событий в Тбилиси на следующие 7 дней в новом формате

- **eventbrite.com** - Грузия/Тбилиси

## Код

**Файлы**:
- `src/bot/handlers/events_handler.py` - обработчик команды /events
- `src/workers/tbilisi_events.py` - получение и форматирование событий
- `src/ai/event_describer.py` - генерация описаний через GPT
- `scripts/test_new_format_with_desc.py` - демонстрация формата

**Использование**:

```python
from src.ai.event_describer import generate_event_descriptions
from src.workers.tbilisi_events import format_events_for_telegram

# Получить события
events = await get_tbilisi_events()

# Добавить GPT описания
events = await generate_event_descriptions(events)

# Форматировать для Telegram
text = format_events_for_telegram(events)

# Отправить боту
await bot.send_message(chat_id, text)
```
