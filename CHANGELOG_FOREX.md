## Механизм работы

### Основной метод: BTC-based вычисление
1. Получаем цены BTC в USD/EUR/RUB за последние 31 день
2. Вычисляем соотношение (EUR/USD = BTC_USD / BTC_EUR)
3. Сравниваем текущее значение с исторически (24h, 30d)
4. Возвращаем процентные изменения

**Преимущества**:
- Не требует API ключей
- Бесплатный доступ к историческим данным
- Надежный источник (CoinGecko)

**Ограничения**:
- Флуктуации BTC могут искажать результаты
- Но дает хорошее приближение

### Fallback метод: База данных
Если основной метод не работает (CoinGecko недоступен):
1. Текущие курсы сохраняются в БД таблице `exchange_rates`
2. При следующем запросе берем историческое значение из БД
3. Со временем БД накапливает историю, fallback становится точнее
