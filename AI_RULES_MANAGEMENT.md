# AI Rules Management

Управляй поведением AI прямо из Telegram бота. Добавляй правила, и AI будет их учитывать при планировании задач.

## Команды

### `/ai-rules`
Показывает все текущие правила с их ID.

```
📋 Ваши правила для AI:
  1. не планировать в понедельник
  2. предпочитаю дневное время (12-17)
  3. избегай спортзалов
```

### `/ai-add <правило>`
Добавляет новое правило для AI.

```
/ai-add не планировать в понедельник
✓ Правило #1 добавлено:
'не планировать в понедельник'
AI будет учитывать это в следующих задачах.
```

### `/ai-del <id>`
Удаляет правило по ID (смотри в `/ai-rules`).

```
/ai-del 1
✓ Правило #1 удалено.
```

### `/ai-reset`
Удаляет ВСЕ правила и возвращает AI к дефолтным настройкам.

```
/ai-reset
✓ Удалены все 3 правило(а).
AI вернулся к дефолтным настройкам.
```

## Примеры правил

### Ограничения по времени
```
/ai-add предпочитаю дневное время (12-17)
/ai-add не планировать ничего после 19:00
/ai-add только срочные дела раньше 10:00
```

### Ограничения по дням
```
/ai-add не планировать в понедельник
/ai-add выходные только для семьи
/ai-add воскресенье только для отдыха
```

### Ограничения по типам задач
```
/ai-add избегай спортзалов в пятницу
/ai-add спорт только утром (7-9)
/ai-add работа только в будни
/ai-add личные дела - только вечер
```

### Логистика и места
```
/ai-add минимизируй поездки в центр
/ai-add предпочитаю места рядом с домом
/ai-add нет дел на левом берегу
/ai-add приоритет - районы Исани и Вака
```

### Погода и сезон
```
/ai-add при дождле предлагай альтернативы в помещении
/ai-add летом только закрытые места
/ai-add избегай уличных дел при ветре > 15 км/ч
```

### Срочность и гибкость
```
/ai-add срочные дела игнорируют рабочие часы
/ai-add но не раньше 7:00 и не позже 23:00
/ai-add гибкие дела группируй в один день
```

### Сложные правила
```
/ai-add если я дома - предлагай удаленные задачи
/ai-add в понедельник минимум обязательств до 18:00
/ai-add покупки - только во вторник и субботу
/ai-add если есть срочные дела - остальное переносить
```

## Как AI использует правила

### Пример 1: Временное ограничение
```
Вы добавили: /ai-add предпочитаю дневное время (12-17)

User: /plan пойти в парк

AI ответит:
✓ Задача разобрана:
📝 Пойти в парк
⏰ 14:00 (вместо 10:00 или 18:00)

💡 По вашему правилу вы предпочитаете дневное время (12-17).
Поэтому предлагаю 14:00.
```

### Пример 2: Ограничение по дням
```
Вы добавили: /ai-add не планировать в понедельник

User: /plan завтра (понедельник) пойти в кино

AI ответит:
❓ Уточнение: По вашему правилу вы не планируете в понедельник.
Может быть, это задача на другой день?
(Или /plan если это срочно)
```

### Пример 3: Срочность переоеrides правила
```
Вы добавили: /ai-add спорт только утром (7-9)

User: /plan СРОЧНО пойти в спортзал

AI ответит:
✓ Задача разобрана:
🔴 Срочно → игнорирует правило про утро
⏰ 10:00 (сейчас)

💡 Срочные дела имеют приоритет и игнорируют
ваши обычные ограничения.
```

## Как правила попадают в AI промпт

Каждый раз когда вы добавляете задачу (`/plan`):

1. Бот получает все ваши активные правила
2. Добавляет их в системный промпт для GPT-4o
3. AI читает правила и учитывает их при планировании
4. Возвращает рекомендацию, соответствующую вашим правилам

```python
# Внутри
rules = await get_ai_rules(user_id)  # Получить все правила пользователя
system_prompt = _format_system_prompt(
    user_profile, 
    weather, 
    custom_rules=rules  # Передать в промпт
)
response = await client.messages.create(
    system=system_prompt,  # AI видит ваши правила
    messages=[{"role": "user", "content": raw_text}]
)
```

## Хранилище правил

Правила хранятся в таблице `ai_rules`:
- `id` — уникальный ID правила
- `user_id` — для какого пользователя
- `rule` — текст правила (то, что ты пишешь)
- `category` — опционально (когда, где, как, ограничение)
- `active` — активное ли правило (1 = да, 0 = удалено)
- `created_at` — когда добавлено

## Советы

1. **Будь специфичен**: "не планировать в понедельник" работает лучше чем "не люблю понедельник"

2. **Используй временные окна**: "спорт с 7 до 9" ясно, "утром" - нет

3. **Мешай разные типы правил**: временные + тип задач + места

4. **Переписывай, не копи**: Если правило не работает, удали и напиши новое

5. **Проверь результаты**: После добавления правила попробуй добавить задачу, посмотри как AI реагирует

6. **Срочные дела override**: Если добавишь "/ai-add не планировать вечером", но потом напишешь "СРОЧНО подготовиться к презентации в 21:00" — AI проигнорирует правило для срочного
